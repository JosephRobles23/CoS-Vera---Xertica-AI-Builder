# Decisiones — Vera-MCP (server MCP multi-tenant)

**Fecha:** 2026-08-19
**Método:** sesión de grilling (frontera por rondas)
**Estado:** ✅ entendimiento compartido confirmado
**Spec de diseño:** ver [`Docs/vera-mcp.md`](../Docs/vera-mcp.md)

> Objetivo: conectar el CoS "Vera" a las cuentas **personales** de Claude/ChatGPT de
> ~50 CLEVEs vía un **server MCP remoto multi-tenant**, para dar contexto del second
> brain y crear/editar tareas desde el chat. Proxy delgado; la data vive en el Drive
> de cada CLEVE vía su GAS Web App (sin mirror central).

## Contexto ya asentado antes del grilling

- **Host:** Cloudflare Workers (descartado GCP `aifirst-dev`: `roles/editor` + proyecto
  IaC/Terraform + probable Domain Restricted Sharing — ver memoria del proyecto).
- **Arquitectura:** proxy → `action:"mcp"` nuevo en `doPost` del stub → `CoSLib.dispatch`
  y funciones `telegram*_` existentes. Sin mirror central de wikis.
- **Auth de usuario:** pairing-code (no Sign-in-with-Google). La capacidad de crear
  tareas NO viene del login, viene del tool + el secreto por-tenant hacia GAS.

## Alcance

- **v1:** los 5 tools (`list_tasks`, `search_wiki`, `get_catalog`, `create_task`, `edit_task`).
- **v1.1 fast-follows** (lógica ya existe): `get_briefing`, `list_blockers`, `meeting_prep`, `team_status`.

## Riesgos aceptados / deuda anotada

- **Re-connect de 50 usuarios** si algún día se migra de host (consecuencia de Q13b).
- **KV free 1k-writes/día** a vigilar (`wrangler tail`); mitigación = Workers Paid $5 (Q14b).
- **DCR deprecado** por CIMD (retiro post-verano 2027) → planear CIMD.
- **v2:** WAF/rate-limit más fino + posible dominio propio.
